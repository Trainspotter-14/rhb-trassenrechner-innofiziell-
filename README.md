# RhB Infra Simulator

Eine moderne Fan-Webseite für virtuelle Infrastruktur- und EVU-Simulationen auf dem Netz der Rhätischen Bahn.

## Features

- Moderner Trassenkostenrechner
- Unterstützung für Allegra und Ge 4/4 II
- Berechnung von:
  - Infrastrukturkosten
  - Energiekosten
  - Gewichtskosten
  - Haltzuschlägen
- Responsive Design für PC und Smartphone
- Modernes RhB-inspiriertes Layout
- Optimiert für GitHub Pages

## Technologien

- HTML5
- CSS3
- JavaScript

## Nutzung

1. Fahrzeug auswählen
2. Gesamtgewicht eingeben
3. Streckenlänge festlegen
4. Anzahl der Fahrten auswählen
5. Kosten berechnen



**Hinweis**

Dies ist ein inoffizielles Fanprojekt und steht in keiner Verbindung zur Rhätischen Bahn oder Dovetail Games.
